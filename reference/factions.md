## 3. 派系技能（20 点解锁）`[二手]`

各阵营声望到达 **20 点**即可解锁对应技能：

| 派系 | 20 点技能 |
|------|-----------|
| 下层区 | 每天**增加一名顾客** |
| 上层区 | 卖货**额外 +15% 收益**（上层买家给 15% 小费） |
| 治安部 | 警察会上门**向你卖货** |
| 黑市 | **来更多小偷** |
| 革命军 | 市场委托（**测试版未开放**） |

这条是「开局直接 +15 全阵营声望」类天赋值钱的根本原因 —— 能**开局就吃到五个派系的第一档效果**。

## 4. 声望折扣公式（本作最有用的一条硬公式）`[二手]`

贴吧·"讨价还价机制，与双向折扣白嫖声望技巧"（版本 048D-REV2-L）实测：

```
实际获得声望 = 成交价 × 0.003 × 声望获取倍率
```

**折扣档位 → 声望获取倍率：**

| 出售折扣 | 倍率 | | 收购折扣 | 倍率 |
|----------|------|---|----------|------|
| -10% | ×2（额外 +100%） | | +10% | ×2 |
| -25% | ×2.5（额外 +150%） | | +25% | ×2.5 |
| -50% | ×3.5（额外 +250%） | | +50% | ×3.5 |
| -75% | ×4（额外 +300%） | | +75% | ×4 |

**1000 块货品的实测收益与"每让利 1 块的边际声望"：**

| 操作 | 实得声望 | 每让利 1 块额外声望 |
|------|----------|---------------------|
| 不打折 | 3 | — |
| 出售 −10% | 5.4 | **0.024** |
| 出售 −25% | 5.625 | 0.0105 |
| 出售 −50% | 5.25 | 0.0045 |
| 出售 −75% | **3** | **0**（与不打折完全一样） |
| 收购 +10% | 6.6 | 0.036 |
| 收购 +25% | 9.375 | 0.0255 |
| 收购 +50% | 15.75 | 0.0255 |
| 收购 +75% | 21 | 0.024 |

**两条结论**：

1. **想在让利换声望，走收购折扣，不要走出售折扣**（收购侧效率高一个量级）
2. **出售侧让利只值得打 −10%**，其余三档边际收益太低；出售折扣更重要的功能是**抬高客人的总预算**
3. **−75% 出售是纯亏**：让利 750 块换来的声望和不让利一模一样

### 4.1 双向交易可以叠加（白嫖声望的核心）

一部分交易是双向的（同时收购 + 出售），此时两种折扣的额外值**相加**：

```
倍率 = 100% + 出售折扣额外值 + 收购折扣额外值
```

以「带空瓶来买水的客人」为例（你收他的空瓶、同时卖他水）：

| 组合 | 倍率 | 卖 1000 块水的实得声望 |
|------|------|------------------------|
| 收购空瓶 +75%（额外300%），**出售不打折** | **400%** | 1000 × 0.003 × 400% = **12**（不打折只有 3） |
| 收购 +75% 且 出售 −10% | 500% | 让利 100，900 × 0.003 × 500% = **13.5** |

**所以：只要把"你不真的在乎的那一项"折扣拉满**（比如空瓶，甚至可以不真收），
就能白拿 4 倍声望，而实际成交的水一分不折。

### 4.2 一条限制：抬价与折扣不能对冲

**当存在声望惩罚时，所有正面倍率被完全无视。** `[二手]`

出售抬价 +10% 会把倍率**固定为 ×−3**；此时无论收购侧打多少折都不会改变这个负值。
→ 想刷声望就不能同时抬价，"变脸王"打法不成立。

> 小红书侧的独立复算（"最大的折扣，反而声望最低？"）给出同一结论：
> **75% 折扣卖出与按原价卖出的声望相同**。其口径里基础汇率写作"每 1000 元 3.99 声望"，
> 与贴吧的 3/1000 不一致，**疑为叠加了上层小费或某系数**，两处并存待核。

## 6. 声望怎么涨、怎么掉

| 行为 | 声望影响 |
|------|----------|
| 与该派系成员成交 | 获得该派系声望（基础 0.003/信用点 × 倍率，见 §4） |
| **抬高售价** | 降低相应派系声望，且**禁用一切正面倍率** |
| **提供折扣** | 提升相应派系声望；部分情况下可折抵金钱（换取商人好感） |
| 收购时多给钱 | 涨声望效率**高于**出售时少收钱（见 §4） |
| 卖对方**改良过的**货并告知 | 加声望 |
| 检举 / 举报通缉犯 | 提升治安部声望，拿悬赏；**降低革命军好感** |
| 卖假货被识破 | 降低相应派系声望 |
| 警报器（已购） | 每天 **+1** 革命军与治安部声望（革命军声望是最难刷的一端） |
| 输送模组配件（监控类挂传输挂件） | 每天 +1 对应派系声望 |

**声望是双向的**：它给你门路与庇护，也让你成为靶子 `[官方]`。
派系之间存在敌对关系，此消彼长，无法同时讨好所有人。

两条相关天赋 `[二手]`：**八面玲珑**（全阵营 +15 声望，且前期举报小偷/革命军不吃派系惩罚）、
**守法公民**（治安部声望 +30）。
