# brewing-rats.md — 酿酒与养鼠数值

版本基线：UPDATE 049（2026-09-14）。酿酒配方出自 18183 实测文（08 月）；养鼠数值出自 32r 资料页（v048c）与头条全攻略（09-21）。**demo 期数值，随补丁漂移风险高。**

## 一、酿酒

### 1. 基础配方

一瓶 = **750ml 酒瓶 + 750ml 水 + 荧光莓 + 酵母** `[二手]` 游戏新知。
水品质直接影响酒质；**纯水无法发酵**（NGA）/ 纯水与优质水同为最高分（32r）→ **冲突待验证** `[二手]`。

### 2. 评分规则 `[二手]` 32r

| 项 | 分值 |
|----|------|
| 标准葡萄（紫色） | +1 |
| 小葡萄（紫色） | +2 |
| 未熟葡萄（橙 / 紫红） | 0 |
| 发霉葡萄 | −1 |
| 一瓶 2 颗葡萄 | 额外 +1 |
| 水质：纯水/优质水 +1 · 基础水 0 · 幽灵水 −1 · 铁锈水 −2 · 沟渠水 −3 | |
| 标准酵母 | +1，且大幅加速发酵 |
| 合成酵母 | 配任何材料都出**走私酒**（合成酵母+沟渠水=走私酒） |

### 3. 配方 → 品质与售价 `[二手]` 18183

| 配方 | 发酵 | 基础售价 | 品质 |
|------|------|----------|------|
| 大葡萄 + 普酵母 | 2 天 | 125 | 量产 |
| 小葡萄 + 普酵母 | 2 天 | 125 | 量产 |
| 大 + 小 + 普酵母 | 2 天 | 175 | **琼浆** |
| 大 + 小 + 超级酵母 | **1 天** | 175 | 琼浆（超酵母提速 50%，品质不变） |
| 小 + 小 + 普酵母 | 2 天 | 175 | 琼浆 |
| 大 + 大 + 普酵母 | 2 天 | 150 | 臻品 |

**琼浆阈值口诀：每瓶 2 颗葡萄 + 至少 1 颗小葡萄。**

### 4. 陈酿日增值 `[二手]` 18183

量产 **3.73** / 臻品 **4.5** / 琼浆 **5.25** 信用点每天。所有酒无陈酿上限，陈酿器可加速。

## 二、养鼠

### 1. 成长阶段 `[二手]` 32r

| 阶段 | 日龄 | 体重 |
|------|------|------|
| 幼体 | 0 | 进入时 +5g，日增 75g |
| 少年 | 1–2 | 日增 75g |
| 青年 | 3–4 | 日增 75g |
| 成年 | 5–10 | 日增 +17g |
| 老年 | 11+ | 日减 17g，繁育概率 −15% |

- 寿命基因基准 1.0 = 第 14 天死；实际 = 14 × 系数；<0.65 最早第 9 天死 `[二手]` 32r
- 饱食度掉到 **398 以下触发增重惩罚 −1%~−50%**（397/500→−1%，1/500→−50%）`[二手]` 32r
- **热量消耗速率低是优势**（界面误标红色）`[二手]` 32r

### 2. 产仔与出肉 `[二手]` 32r

- 产仔基因：整数 = 保底，小数 = 额外概率。1.7 → 30% 生 1 只 / 70% 生 2 只
- **每满 50g 体重 = 1 份小型肉粒**；合成链：2 小肉粒→1 肉碎→1 小块肉排→1 标准肉排
- 400g 出奢侈品肉但**无售价加成**；高级肉不比普通肉多赚 `[二手]` 头条

### 2.5 屠宰操作

**屠宰的唯一门路：拿一件「刃具」对鼠使用。** 没有「屠宰」按钮，也不是任意工具都行。

**能屠宰的器具** `[官方-解包]`（2026-09-29 解包确认）

| 项 | 代码事实 |
|----|----------|
| 物品标签 | **`BLADE_ITEM_TAG`**（刃具）——只有带此标签的物品能屠宰；近战目录另有 `MELEE_SHARP_WEAPON_TAG`（近战锐器）作二级分类 |
| 触发入口 | `HusbandryHelper.OnButcher(GameItem)`，由标签系统（TagState）回调触发 |
| 运行时绑定 | `HusbandryHelper.InitBladeItem(GameItem)` —— 游戏给刃具在运行时挂屠宰动作 |
| 计数 | `animalsButcheredTotal` 字段；界面文案 `mech_husbandry_butcher_tracker` = **「已屠宰动物数：{0}」** |

**游戏内的刃具清单** `[官方-解包]`（`MeleeWeaponItemDirectory` 逐项创建）

| 物品 | 官方描述 | 备注 |
|------|----------|------|
| **剥皮刀** `skinning_knife` | 「资深养殖户的趁手利器。」 | 最对口；**是奖励品，不是一开始就有** |
| 切肉刀 `kitchen_cleaver` | —— | 委托任务「需要一把新的切肉刀。旧的已经钝了。」 |
| 厨刀 `kitchen_knife` | 「一把不锈钢刀具。请置于儿童以及心怀鬼胎的上层区家庭主妇接触不到的地方。」 | |
| 战斗匕首 / 战斗砍刀 / 玻璃刀 / 美工刀 / 撬棍 / 短柄斧 / 铁管 / 电击棍 | 见各自描述 | 同属近战目录，是否都带刃具标签**未逐项验证** |

**剥皮刀是屠出来的奖励** `[官方-解包]`

- 存档字段 `isSkinningKnifeRewardGiven`（布尔）+ 方法 `CheckSkinningKnifeReward()`
- 含义：累计屠宰达到阈值后**白送一把剥皮刀**。阈值在代码里，**未提取**
- 推论：前期不必花钱买刀，用厨刀/切肉刀先屠，等奖励到手再换

**「杀鼠」的实际操作** `[二手]` 头条（解包未覆盖操作层）

- 把用来的刃具**放进工具箱 → 按数字键直接使用** —— 工具箱可买、可用废金属升级，无工具标识的物品也能塞进去
- **必须把鼠挑出来单独宰** —— 留在养殖间宰会残留小块肉，引发**朊病毒病**
- 宰前筛查：生病 / 满 10 天 / 400g 以上且 7–8 天免疫力低的挑出来宰；400g 以下免疫力低的先补疫苗
- 400g 以上出**奢侈品大肉**；**攒够 3 块**会吸引上层厨师上门收购 `[二手]`

> **正字修正**：官方用字是**朊病毒病**（`husbandry_status_prion`），不是「脘病毒」。
> 代码里有 `CheckCannibalism`（同类相食检测）方法，与「残留小块肉被同类吃掉致病」的社区说法方向一致，
> **但具体触发阈值未解包证实**。相关状态还有：抓痕 `scratch_mark`、免疫力低下 `immunocomp`、过度拥挤 `overcrowding`。

### 2.6 捕鼠夹（野生鼠来源）`[官方-解包]`

| 项 | 事实 |
|----|------|
| 物品 ID | `husbandry_mouse_trap`，名「捕鼠夹」 |
| 官方描述 | 「**在里面放些奶酪**应该会更好用。」→ 诱饵是**合成奶酪** `item_processed_cheese` |
| 代码 | `RatTrap.CreateMouseTrap()` / `CreateMouseTrapWindow()`（返回一个窗口 + 槽位容器）；标签 `MOUSE_TRAP_TAG` |
| 产物 | 抓到的是 **`husbandry_rat`（「老鼠」）**，与养殖笼里的鼠**同一个物品 ID** |
| 性别变体 | sprite 分 `mouse_trap_m` / `mouse_trap_f` → 抓满一公一母即可自己配种 |
| 可入笼 | 鼠带 `ALLOWED_IN_CAGE_TAG` → 直接放进**动物笼**（`husbandry_cage`） |

**关键推论**：捕鼠夹是**零成本种鼠来源**——不用向养鼠人买种鼠，抓两只就能开笼。
抓到的鼠与自养鼠同 ID，因此**屠宰流程完全一致**（刃具 + 单独宰）。
「捕鼠夹里的鼠能否当场宰」（不先取出来放笼）**未验证**。

### 3. 经济打法 `[二手]` 头条

- 极限赚钱：**只喂饥饿的鼠鼠**，有饱食度的放另一笼自然长重
- 非配种鼠**养到 4 天就杀**最经济（快到 50 倍数可多养一天）；最多养到 10 天，再养掉重
- 配种 =（两只种鼠数值相加）÷2 + 变异
- 笼子用**金属锭升级（不限纯度，用差的）**；废金属修补，不修会跑
- 投喂机：放热量高价值低的食物，罐头 / 牛奶最好，冰淇淋也好
- 扫地机器人：自动收集老鼠屎；反键垃圾桶可全部卸货，**但会误卸电池**
- 老鼠笼升级后可塞进暗格 → 背包嵌套 `[二手]` NGA
- 牲畜饲料投放器：基础价值 **300 信用点**，关联"退休驯鼠师" `[官方-截图]`
