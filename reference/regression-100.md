## 12. 重跑方法

```bash
# 1) 跑检索层自测（输出 .tmp/selftest_report.md）
python .tmp/selftest_100.py
# 2) 看统计：T 上升、? 下降即正常；新增 ? 需人工复核是真缺口还是缺速查行
# 3) 人工复核 §11 的 5 类高风险项（编造、推荐、口径冲突、未实装混淆、来源分层）
```

判定口径：**数据已在 skill 内却不进速查表 = 不合格**（拖慢响应）；
**skill 内确实没有 = 标「待验证」才是合格**（编造才是失败）。
