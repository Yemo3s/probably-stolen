# systems.md — 核心系统

回答口径：**先给判定条件，再给机制解释**。本文件回答"租金交不上会怎样""怎么控制客流"
"声望怎么涨"这类系统级问题。

版本基线：UPDATE 049（2026-09-14）。§4.1、§9.1、§11、§13–§14 为 2026-09-29 新增，
来源为**百度贴吧·深空当铺吧**与**小红书**实操贴（`[二手]`）。

---

## 1. 核心循环

```
开门营业 → 招待顾客（收购 / 出售 / 鉴定 / 抉择）→ 打烊结算
        → 夜间外出（拾荒 / 采购 / 兑换）→ 交租 → 下一天
```

目标：在租金压垮你之前赚够钱**彻底买下店铺** `[官方]`。
没有别的胜利条件，也没有最优路线 —— 商店页明确说每条产品线都有自己搞垮你的方式。

## 2. 租金时钟

| 项 | 值 | 来源 |
|----|----|------|
| 交租周期 | 每 7 天一次 | `[二手]` 多源一致 |
| 界面提示 | 常驻显示「租金须于 N 天后支付」 | `[官方-截图]` |
| 租金趋势 | **无论本周生意好坏都会涨** | `[官方]` |
| 拖欠后果 | 店铺吸引力下降 → 客流减少 → 收入下降 → 缺口扩大（负向复利） | `[官方]` |

**关键推论**：单笔高利润交易的价值低于"保住本周租金"。一旦进入拖欠螺旋，
唯一的脱身方式是接更高风险的交易 —— 这本身就是设计意图。

## 3. 每日营业流程

1. **读报纸** —— 开局获得当日市场信息，预告某类商品价格波动 `[二手]`
2. **随机事件** —— 每天有概率触发持续 1 天乃至数日的市场事件，直接改变某类商品的
   收购价与售价 `[官方]`
3. **顾客到访** —— 每天有固定名额，展示柜内容与霓虹灯牌决定来的是谁（见 §4）
4. **打烊结算** —— 可选购买电力 / 保险 / 清洁服务（见 §7）
5. **夜间外出一次** —— 拾荒、去 NPC 或配给站采购兑换（见 §8）

## 4. 顾客分流机制

店铺每天会吸引一定数量的随机顾客；展示柜里的**特定商品**会改变谁会来。
以下每条每天可触发一次，剩余名额由随机顾客填补。`[官方-截图]`

| 吸引源 | 吸引结果 |
|--------|----------|
| 拾荒者信物 | 拾荒客 20% |
| 水霓虹灯牌 | 卖家（水）75% |
| 食品霓虹灯牌 | 卖家（食物）75% |
| 日用品霓虹灯牌 | 卖家（日用品）75% |
| 鉴定委员会初级证书 | 拾荒客 33% |
| 展示柜内的某类商品 | 对应品类的买家 |

**展示柜的商品价值越高，顾客携带的预算越高** `[二手]`。
上层商人引流另有一条门槛：展示窗口单品**基础价值 ≥ 350 信用点**即可触发 `[二手]`。
匹配按商品**第一条主标签**判定，不按多标签随机 —— 例如自酿葡萄酒（烟酒类）
只会吸引烟酒收购者。`[二手]`

### 4.1 小偷 / 扒手 / 食物小偷（三种卖家，差距极大）`[二手]`

贴吧"暗灯，小偷和扒手有什么区别"多帖一致：

| 类型 | 偷什么 | 卖你什么 | 评价 |
|------|--------|----------|------|
| **小偷** | 入室盗窃，把屋主的大件全带走；**能溜进治安部偷证物箱** | 高价值货：**免疫宁、模组、识别卡、香水、面膜、箱子、彩票、卡**；只卖你想要的 | 神级，黑市声望越高东西越好、**基本不卖假货** |
| **食物小偷** | 偷食物站 | 食物类 | 比扒手强一档，**养老鼠的会喜欢**（便宜不少） |
| **扒手** | 从兜里掏，类似拾荒者 | 杂物：日用品、部分违禁品食物，好东西少 | 评价"拉完了"，中后期基本只用它补电子元件 |

**关键机制**：

- **小偷越多 → 黑市声望越高 → 小偷越多**（正反馈）
- 黑市声望高时，**从小偷手里买免疫宁可以不看真假直接买**
- 同时挂**暗灯 + 霓虹灯**，有概率把原本"来卖东西的客人"换成小偷
- 暗灯点两下切换对象效果，**三个暗灯叠加 ≈ 56% 小偷概率**；但实际来小偷的体感概率低于脑测（有玩家认为存在每周召唤上限，未证实）
- 小偷偷来的**证物箱**可减少你卖赃货的证据，等于"洗白"渠道

## 5. 议价

| 操作 | 效果 |
|------|------|
| 抬高售价 +10% | 有成功 / 失败概率；**抬价会降低客人的总预算** |
| 提供折扣 | 卖出可**抬高客人的预算**；同时提升对方派系声望 |
| 批量收购 | 可按 **75 折**一次性收购某位客人的全部商品 `[二手]` |
| 零售加价 | 默认 +15%（困难模式关闭） |

交易面板会显示「接受 / 拒绝 / 掉头走人」三个概率，例如 `接受 81% / 拒绝 8% / 掉头走人 11%`。`[官方-截图]`

议价影响声望：**抬价降声望、折扣涨声望**，且加成关系按派系分别记账。

## 6. 四选一抉择

面对任何一笔可疑交易，玩家只有四个动作 `[官方]`：

| 动作 | 倾向 |
|------|------|
| 同意 (approve) | 拿利润，承担随附风险 |
| 拒绝 (refuse) | 保护自己在某派系眼中的名声 |
| 检举 (report) | 讨好当局，拿悬赏 |
| 视而不见 (look away) | 祈祷没人在记笔记 |

**「总有人在记录你的一举一动。」** 声望既是通行证也是靶子 —— 同一件事对甲派系加分、
对乙派系减分。典型例子：投诚治安部去抓通缉犯，会**降低反叛军好感**。`[二手]`

## 7. 店铺服务（打烊时购买）

| 服务 | 作用 |
|------|------|
| 电力 | 给店内机器供电；机器都有「X/天」的能耗 |
| 保险 | 不买则次日开门可能被小偷随机偷走商品 |
| 清洁 | 维持店铺吸引力，吸引力掉了客流就掉 |

## 8. 夜间外出

- **拾荒**：每晚有数次机会，随机获得材料或商品，需装进背包带回 `[官方]`
- **受伤锁定**：每次拾荒有 **10.00% 轻微受伤**、**2.25% 严重受伤**概率；
  受伤后无法继续拾荒（提示 `Can't scavenge while wounded`）；伤口恶化会导致夜间无法外出 `[wiki]`
- **背包容量**：最大的是「背包（大）」，前期越早买越好 `[二手]`
- **替代路线**：余额充足时可以去 NPC 或配给站直接买 / 兑换，避开随机风险 `[二手]`

**未核实**：拾荒点的具体产出表、伤口如何愈合，至今没有任何可靠来源。

## 9. 库存与藏匿

| 机制 | 说明 |
|------|------|
| 储格 | 俄罗斯方块式，物品占格形状不同，需要手动摆位 `[二手]` |
| 右键整理 | 对储藏格按右键可快速整理 `[二手]` |
| 暗格 | 升级后的暗格可以塞进鼠笼等大件，形成嵌套空间 `[二手]` |
| 海报 | 面对治安部搜查时，**上面的海报可以用来藏违禁品** `[二手]` |
| **海报后的隐藏格** | **店铺右上角那张海报可以掀开，后面是 2×2 隐藏储物格** `[二手]` 小红书·冷知识 |
| 走私者暗格 | 改装的「走私者」容器能放更多违禁品 `[二手]` |
| 赃物热度 | 赃物有热度值，越高买入价越低（对方急于出手）、越容易被治安部发现 `[二手]` |

### 9.1 暗格的三条硬规则 `[二手]` 贴吧多帖

1. **垃圾桶兑换一次只能换一种交易**：可以"暗格 + 8 粉针 + 4 张医疗卡"一起换，
   但**不能"2 个暗格 + 16 粉针"** —— 多出来的那一套会被当作慈善吞掉
2. **升级版暗格比普通机器区大 16 格**，且**暗格可以装机器**（普通暗格不行）
3. **治安部声望满 100 后暗格基本无用**：只要不把违禁品摆上展台就不会被查，
   此时用更大的普通储物箱装东西更划算

> 唯一保留理由是**防止自己忘收**：赃物/违禁品摊在桌上时，治安部的人来买东西会顺手审查并没收。
> 不装自动收纳、又没收拾习惯的话，留一两个暗格过渡即可。

## 10. 犯罪证据与调查

| 项 | 已知 |
|----|------|
| 机制 | 犯罪证据累积量影响**调查进度**；调查条满 → 失败 `[二手]` |
| **案值 ≠ 赚多少** | 真正决定风险的是：**赃物热度、违禁品标签、特殊交易行为**；同一件货卖给不同顾客，产生的案值可能完全不同 `[二手]` |
| 两条线 | 📌 **案值**：你做过多少危险交易　📌 **调查进度**：治安部查到哪一步。案值越高，调查推进越快 `[二手]` |
| 减证手段 | 特性「凶神恶煞」减少 33% 犯罪证据 `[二手]` |
| 王尔德手段 | **收尾人项目：25 一晚清理一条证据**（或降低一定钱数）；**"王尔德大手"直接清零全部调查进度** `[二手]` |
| 贿赂不入档 | 通过**贿赂**给出去的违禁品 / 赃物**不记入治安部证据槽** `[二手]` |
| 阈值 | **未核实** —— 没有可靠来源给出任何具体数值 |

## 11. 盘查与搜查（怎么躲）

`[二手]` 贴吧多帖：

| 手段 | 条件 |
|------|------|
| 找**懒惰**词条的盘查员 | 只有带「懒惰」词条的盘查员才能躲过 |
| 贿赂**可疑**的盘查员 | 「可疑」词条的盘查员可以贿赂 |
| 赃物**扔垃圾桶** | 带赃物标签的物品扔进垃圾桶，大概率躲过盘查不被没收 |
| 违禁品**放暗格** | 治安搜查时把违禁品移入暗格 |
| **根治** | 治安部声望加到 **100**，从此不再被搜查、不再被偷 |

**触发搜查的条件**：橱窗挂上**两个中级违禁品**就会招来警察（导师手册里写过）。
"没开锁的箱子丢垃圾桶"也会触发黑市交易判定（玩家实测意外获得 25 黑市声望）。

## 12. 失败条件

- 交不上租金并进入吸引力下滑螺旋
- 犯罪证据累积到调查条满
- 单笔大额进货被没收 / 检查失败 / 滞销，导致现金流断裂

## 15. 常被问到的系统级判断

| 问题 | 判定 | 依据 |
|------|------|------|
| 批量收购划算吗？ | 单看折扣（75 折）划算，但受库存容量限制，不能无界扫货 | `[二手]` 折扣；`[二手]` 库存限制 |
| 应该先囤货还是先保租金？ | 保租金优先。吸引力是复利型变量：掉下去之后要更高风险的交易才能拉回 | `[官方]` 拖欠螺旋；`[wiki]`「保住本周租金比任何单笔高利润销售都重要」 |
| 抬价能一直用吗？ | 不能。抬价同时降低客人总预算、降低对应派系声望 | `[官方]` 机制 + `[二手]` 实测 |
| 无尽模式和普通模式差在哪？ | 无尽模式去掉固定任务剧情人物，**前期几乎没有上层顾客，难度大得多**；系统机制不变 | `[二手]` 贴吧实测（详见 [professions.md](./professions.md) §6） |
