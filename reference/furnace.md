### 模组三属性的换算规则 `[二手]`

| 属性 | 规则 |
|------|------|
| 质量 Quality | **每满 100%** 提升或降低一个纯度阶段；**只有 100 的整数倍生效**，99% 等于 0 效果 |
| 效率 Efficiency | **每 12.5%** 增加或减少 1 点能量需求；**只有 12.5 的整数倍生效**，12% 仍按 8 能量/天算 |
| 性能 Performance | **无影响**，可以忽略 |

## 2. 特殊模块

| 模块 | 效果 |
|------|------|
| 高炉模块 | 将 **3 种材料** 炼制成 **2 个金属锭** |
| 废品处理模块 | 将 **6 个废料** 炼制成 **4 个废金属** |

废品处理模块是玩家反馈中早期性价比最高的一个 `[二手]`。

## 3. 配方与纯度

纯度阶梯（低 → 高）：**低 < 普通 < 高 < 非常高 < 完美**

| 配方 | 产出纯度 | 需要模块 |
|------|----------|----------|
| 2 废金属 | 低纯度 | 基础 |
| 1 废金属 + 1 金属矿石 | 普通纯度 | 基础 |
| 2 金属矿石 | 高纯度 | 基础 |
| 3 废金属 | 低纯度 | 高炉 |
| 2 废金属 + 1 矿石 | 普通纯度 | 高炉 |
| 1 废金属 + 2 矿石 | 高纯度 | 高炉 |
| 3 矿石 | 高纯度 | 高炉 |

## 4. 助熔剂（Flux）

- 在配方中加入助熔剂，**提升纯度 1 级**
- 但它会**禁用熔炉质量的影响** —— 100% / 200% / 0% 质量结果完全相同

**推论**：想靠质量堆纯度的路线，不能同时用助熔剂。

### 4.1 品质其实更看材料（2026-09-29 补入）`[二手]`

| 配方 | 产物品质 |
|------|----------|
| 废金属 + 助熔剂 | **中等品质**金属锭 |
| 金属矿石 + 助熔剂 | **极高品质**金属锭 |

玩家常用组合：**高炉模组 + 效率模组**。熔炉**堆效率即可** ——
"质量加成太亏，除非大后期模组多到没地方放" `[二手]`。
高级助熔剂来源：下层区稀有品商人会卖，工程箱也有小概率开出 `[二手]`。

## 5. 完美锭怎么炼

前提：**全程不使用助熔剂**。

| 情形 | 所需质量 |
|------|----------|
| 无高炉模块，2 矿石配方 | +200% 质量 |
| **有**高炉模块 | +300% 质量（因为高炉会忽略 100% 质量加成） |
| 废金属路线 | 需要 +400% ~ +500% 质量 |

> 原文里"高炉忽略 100% 质量加成"这条容易被漏，是完美锭门槛突然变高的原因。

## 6. 电力链

电池耗光后需要**充电装置**恢复电量 —— 所以真正的生产线是：

```
熔炉（耗电） ← 电池 ← 充电器
```

电力服务是打烊时购买的店铺服务之一，电池本身占库存。

## 7. 玩家推荐的机器优先级 `[二手]`

```
熔炉炼制金属 > 充电器 > 冰箱 > 滤水器
```

理由：水靠收购 + 用食物点数兑换最稳妥，产能机器优先给金属线。

## 8. 各机器的模组配置总表（2026-09-29 补入）`[二手]`

贴吧"每种机器堆什么树脂比较好啊？"（模组颜色：**红=性能（产量）、绿=效率（耗电）、黄=质量**）：

| 机器 | 该堆什么 | 关键档位 |
|------|----------|----------|
| **熔炉** | **效率**即可 | 常备一个废品处理模组；高炉模组 + 高级催化剂按熔炉数量配足 |
| **集水器** | **性能 + 质量并行** | 质量达 **50 / 100 / 150** 档；不强求硬追；基础耗电低，**不必堆效率** |
| **净水器** | 放几个效率，其余位置养自学习 | 评价"有点烂" |
| **陈化器** | **质量** | **125 一个档**，基础至少 125、最好 250；再往上浪费神经模块，耗电太高 |
| **警报器** | **效率** | **100 以上即可**；可放**警报模块**给某个阵营每日 +1 好感（换模块可改阵营） |
| **投影仪** | **性能 + 质量** | 按店面算魅力得分（去掉 % 号即加分），前期直接升级店面更省 |
| **制卡器 / 密码解序器** | **性能 + 效率** | 性能 **75** → 2 天指挥卡；**100** → 1 天工程/医疗/治安卡；**150** → 1 天服务卡 |
| **模块通用** | **自学习最稳** | 能把带负面的大模块负面洗掉并拉到高数值；见到就拿（除非钱紧） |

**两条实测读数**（玩家原文）`[二手]`：

- 净水器 `性能 +194% / 效率 −121%` → **2–3 天处理一桶幽灵水**
- 集水器 `质量 +156% / 性能 +214%` → **约 3140cc 纯水/天**（可直接纯水自由）
- 后期因为暗灯拉小偷 + 无限开工程箱拿大量高级涡轮增压器，
  配一个大格子自学习模组堆出 `150 质量 + 高性能` 的集水器，就能批量产水：
  **一个涡轮增压器 ≈ 3 天一个 6L 大桶纯水**，且增压器本身可存四五十个 `[二手]`

**机器排放（玩家实测的最优机器区布局）** `[二手]`：8 机器位 / 16 电池位；按接触矩阵数排布，
接触 4 矩阵的 4 个机器位放密码机 / 投影仪 / 熔炉这类"大头"。
