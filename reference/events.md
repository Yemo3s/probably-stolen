# events.md — 事件与报纸系统

来源：**2026-09-29 解包 `Mechanic` 表的 `event_*` 键（132 条）`[官方-解包]`**。
此前该模块只有社区转述（"报纸能看涨跌"），这是首次拿到完整事件清单。

---

## 1. 事件的三段结构

每条事件在游戏内有三个字段，全部来自解包：

| 字段后缀 | 用途 |
|----------|------|
| `_news` | **报纸标题**（如"水处理厂故障，供水面临告急"） |
| `_desc` | **报纸正文**（说明事件与对市场的影响） |
| `_display` | **日历标签**（如"供水危机"）—— 开店前在日历里就能看到 |

**玩法含义**：日历标签是**当日价格走向的预告**，报纸正文是**解释**。所以"开店前先看日历"是可复现的，
不是玄学。

---

## 2. 事件七大分类

| 前缀 | 数量 | 性质 |
|------|------|------|
| `cosmetic_` | 16 | **装饰性事件，明确不影响市场**（正文常写"对市场影响甚微"） |
| `normal_` | 20 | 普通市场事件，**直接改变某类商品的价格** |
| `op_` | 20 | **派系行动**，改变秩序、供给与需求 |
| `evidence_` | 1 | 证物库失窃（牵涉案件证据流入市面） |
| `lottery_` | 1 | 彩票开奖 |
| `mortgage_` | 1 | 按揭还款 |
| `rent_` | 1 | 交租日 |
| `cartel_` / `wanted3` | 2 | 卡特尔来访 / 通缉事件 |

| 奥克西莫成瘾 oxymore | 奥克西莫成瘾加重 | 医疗与治疗服务 ↑ |

**可执行的套利逻辑**：日历出"供水过剩"→ 当天不要卖水，改**收水**；
出"供水危机"→ 囤的水当天高价出。这就是"涨价的卖、打折的收"的数据依据。

## 4. 派系行动（`op_` 类，改变游戏规则）

| 事件 | 效果 |
|------|------|
| 全站严打 crackdown | **所有区域更严格盘查** |
| 加强巡逻与检查站 patrols | 压制革命军与黑市活动 |
| 戒严 martial_law | 宵禁 + 检查站 + 监控，压制革命军与黑市 |
| 治安部预算增加 budget_increase | 治安部可开展更多行动 |
| 突袭黑市 raid_bm | 黑市贸易受阻 |
| 突袭革命军 raid_rev | 革命军被削弱 |
| 革命军突袭治安部 raid_sec | 治安部影响力 ↓、医疗物资需求 ↑ |
| 革命军突袭上层区 raid_upper | **日用品供应 ↑**（赃物转卖下层区） |
| 下层区暴乱 riot | **食物 ↑ + 武器 ↑** |
| 下层区帮派开战 gang_war | **医疗物资需求 ↑** |
| 工人大罢工 worker_strike | **食物与水供应受干扰** |
| 非法武器走私抵达 weapon_shipment | **武器供给 ↑、价格 ↓** |
| 武器需求增加 mob_secret | 神秘买家对武器需求 ↑ |
| 革命力量动员 mobilization | **武器 ↑↑ + 医疗 ↑ + 护甲 ↑** |
| 食物赈济 / 日用品援助 / 医疗援助 | 派系施恩，缓解紧张 |
| 指挥部预算 / 工位调动 | 秩序类 |

**关键**：`op_` 类是**做武器线、药品线的主要机会窗口** —— 动员与暴乱让武器价暴涨，
戒严与严打则让违禁品风险陡增。事件本身给出了"该不该现在出货"的信号。
