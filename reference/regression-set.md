# regression-set.md — 会问率与回答质量回归集

> **全量版见 [regression-100.md](./regression-100.md)**（124 问，含每题落点与首跑实测）。
> 本文件是**精选子集**，用于快速抽查高价值/高风险问法。

用途：每改一版 SKILL.md 或 reference 后重跑一遍，看两件事：

1. **命中率** —— 该触发的时候触发了没有
2. **满意度** —— 回答是否一次到位，还是需要追问才满意

会问率口径：**提及游戏话题的轮次中，触发本 skill 的轮次占比。**

**最近一次重跑：2026-09-29（v0.4.0，接入贴吧 26.5 万字 + 小红书 1.9 万字一手数据后）。**

## 判定标准

| 检查项 | 通过条件 |
|--------|----------|
| 结论前置 | 第一句就是答案或判定条件，不是背景介绍 |
| 极简 | 速查表命中时 ≤5 行、零文件读取 |
| 已核实标注 | 每个数值都带版本号，每条事实都带 `[官方]` / `[wiki]` / `[二手]` |
| 未核实显式 | 不确定的内容单独成段并标「未核实」，没有混进结论 |
| 条件分支 | 取舍类问题必须是 `如果 <前置> → 走 <分支>；代价 <...>` 格式，**不出现"推荐/最好选/优先"** |
| 无编造 | 没有被问到的具体数字（价格、阈值、掉率）凭空出现 |

## 当前已知薄弱项（重跑时重点看）

1. **B2 / C3** —— augs、器官贩子这类"官方没公开"的问题，最容易诱发编造。
   现在 augs 有了社区判法，**必须同时说"这是玩家实测、非官方规则"**。
2. **B4** —— 起始路径数量存在来源冲突，最容易答错。
3. **C2** —— "该玩哪个职业"是典型的"玩家想要建议"型提问，最容易被带偏成主观推荐。
4. **A5 / B5 / B6** —— 三条 2026-09-29 新增的高频问题，速查表已覆盖，**验证是否命中而不掉进 reference**。
5. **来源分层** —— 贴吧/小红书实测帖可复现性高但仍属 `[二手]`，
   最容易在"多帖一致"时被误升级为 `[官方]`，重跑时重点检查标注。

| E9 | 怎么 100% 确认柜台对面是改造体？ | **改造体扫描仪** —— 官方明写"以 100% 的准确率确认"，代价是极度耗电 |
| E10 | 武器许可证会被吊销吗？ | 会：1 级治安部声望 **< 0** / 2 级 **< 30** / 3 级 **< 60** |

**E 组判定**：
- 凡引用解包数据，标注必须是 `[官方-解包]`（不是 `[官方]`）。
- **E4 是陷阱题** —— 只答"13 个"而不说明 demo 范围，算不合格。
- 凡遇到 `{0}` 占位符，**必须保持未知**（如"折扣具体百分比待提取"），不得填社区读数当真值。
