# appraisal-calc.md — 鉴定计算手册（官方文本全量落盘）

**用途**：玩家报出待鉴定物品的特征 → 按本表算出**精确价值**，替代"玩家自己翻游戏内鉴定手册"这个动作。
**数据源**：游戏内鉴定手册全文（`[官方-解包]`，本地化键 `book_*` / `ins_*`，UPDATE 049 基线）。这是**最高等级**来源 —— 与社区口径冲突时以本文件为准。

---

## §0 使用规范（三条硬规则 + 输出模板）

### 硬规则

1. **赝品优先于一切**：命中任一"赝品条件" → 直接给该品类的地板价（或"不可使用"），**不再累加任何加成**。
2. **地板价兜底**：加减算完，与地板价取**较大者**。判低于地板价 = 严重错误。
3. **不猜未报项**：玩家没说的项按"未提及"处理，**不许代为假设**；只有当手册规定"该项缺失即为赝品"时才因缺失而判赝。

### 信息采集模板（玩家只给文字时，一次问全）

> 报这四类就够了：**① 品类 ② 各判据项的观察结果 ③ 包装/外观状态 ④ 有无缺失项**
> 例：「肋明治，包装完好，批次 428年5月，工厂编号 05，有达夫雷标志，芝麻面包+加量酸黄瓜，双层肉饼」

### 输出模板（≤6 行）

```
最终价值：<数字> 信用点   ← 或「赝品，地板价 40」/「不可使用」
算式：<基础> + <项A> + <项B> − <项C> = <小计>；地板价 <N> → 取 <结果>
依据：<手册名> §<节>
待确认：<只列真正影响结果、且玩家没说清的项>
```

**图片输入**（玩家上传截图）的额外一步：先把读到的关键项**回读确认**（"我读到工厂编号 05、日期 428/05，对吗？"），确认后再算 —— 像素字体有误读风险，这一步不能省。

## §1 肋明治 Ribwich（基础 150 / 地板 40）

手册：肋明治鉴定指南（`book_ribwich_*`）

| 判据项 | 条件 | 加减 |
|--------|------|------|
| **包装** | 塑料包装**缺失或已被撕开** | **一律 40**（终局，不再累加） |
| **赝品** | 命中下列任一赝品条件 | **一律 40**（终局） |
| 生产批次 | 第一批次 **425/01–429/12** | **+80** |
| 生产日期 | 首月 **01/425** 或 末月 **12/438** | **+50** |
| 生产日期 | 缺失 / 无效 / 不在两批次范围内 | **赝品** |
| 包装工厂 | 高品质：**01、02、05、08、21、34** | **+50** |
| 包装工厂 | 低品质：**07、15、18、26、31** | **−50** |
| 包装工厂 | 编号缺失 / 无效（共 **35** 家工厂） | **赝品** |
| 豪华版 | **同时**具备芝麻面包 **和** 加量酸黄瓜 | **+300** |
| 豪华版 | 只有其中一项 | **赝品** |
| 双层肉饼 | 罕见，包装机故障产物 | **+800** |
| 达夫雷标志 | 缺失 / 错误 | **赝品** |
| Ribwich 贴纸 | **第二批次**缺失或错误 | **赝品**（第一批次本就无贴纸，不扣） |

**官方示例**：第二批次正品 = 150 + 工厂加成 +（可能的豪华版/双层肉饼项）。

## §2 仿生机械手 Hand（基础 100 / 地板 50）

手册：仿生机械手鉴定指南（`book_hand_*`）

| 判据项 | 条件 | 加减 |
|--------|------|------|
| 基础 | 所有机械手 | **100** |
| 材料 | 碳复合材料 `book_hand_carbon` | **+50** |
| 材料 | 铝合金 / 镀金 | **手册未给数值**（仅列为条目，不编） |
| 品相 | 磨损 | **−35** |
| 品相 | 受损 | **−85** |
| 品相 | 无 | 0 |
| 控制接口 | EMG+ | **+45** |
| 控制接口 | 规格不明 | **−60** |
| 控制接口 | 神经接口 | **手册未给数值**（仅列为条目） |
| 附加组件 | 装甲 / 刀刃 | **手册未给单项数值**（"加成为独立计算、可叠加"） |
| **套装加成** | **战术型**：碳复合材料 + (EMG+ 或 神经接口) + 无磨损/受损 + **同时**有装甲与刀刃 | 套装（值未给） |
| **套装加成** | **豪华型**：镀金 + 神经接口 + 无磨损/受损 + 任意/无附加组件 | 套装（值未给） |

**官方示例 1**：基础 100 + 碳复合材料 50 − 磨损 35 + EMG+ 45 = **160**
**官方示例 2**：基础 100 − 受损 85 − 规格不明接口 60 = −45 → 底板 **50**（"不可低于 50"）

> 注：社区旧口径里的「神经链接控制器 +120」在官方手册中**不存在**，属误传。

## §4 化学制品纯度（7 档 → 价格修正）

手册：化学入门指南（`book_chem_*`）。纯度用**成分光谱仪（化学扫描仪）**读。
修正基数是**物品基础价值**。

| 档位 | 纯度区间 | 价格修正 | 键 |
|------|----------|----------|-----|
| 纯品级 | 99% 以上 | **+200%** | `pure_grade` / `val1` |
| 药用级 | 90%–99% | **+125%** | `pharma_grade` / `val2` |
| 近药用级 | 80%–90% | **+75%** | `near_pharma_grade` / `val3` |
| 街头标准级 | 60%–80% | 无修正 | `street_standard_grade` / `val4` |
| 掺兑级 | 45%–60% | **−45%** | `cut_product_grade` / `val5` |
| 垃圾级 | 30%–45% | **−75%** | `junk_grade` / `val6` |
| 淀粉级 | 低于 30% | **−95%** | `starch_grade` / `val7` |

> 对齐方式：`val1..val7` 修正值单调递减，与档位由高到低一一对应（推断，与官方 7 档数量一致）。
> 官方明示：**部分顾客会携带化学扫描仪核验标签纯度** —— 虚标纯度会被当场拆穿。

## §5 共和国食品券 Stamp

手册：共和国食品券真伪鉴定手册（`ins_stamp_*`）

| 判据项 | 条件 | 结论 |
|--------|------|------|
| **面值** | 仅发行 **40 / 80 / 120 / 160 / 200 / 240** 信用点 | 其他面值 → **赝品** |
| **防伪标** | 面值 **≥160** 才带防伪标；**<160 无防伪标属正常** | 不因缺失而判赝（关键区别） |
| 芯片 | 缺失或损坏 | **真品也不可使用** |
| 商标 | 缺失 | **赝品** |
| 字母/字体/颜色 | 拼写错误、文本错位、字体差异、缺字母 | **赝品** |

## §6 免疫宁注射器 Injector（最难品类，但有机械判据）

手册：免疫宁免疫调节注射器用户手册（`ins_inj_*`）

| 判据项 | 条件 | 结论 |
|--------|------|------|
| **序列号** | 必须 **7 位**；前 3 位 = 批次号；有效范围 **1250000–4559999** | 越界/位数不符 → 赝品 |
| **召回批次** | 批次号 **250、251、301、355、385、386、421** | **不可使用** |
| 标签 | 缺失 | **伪造** |
| 标签 | 拼写错误 / 缺公司名 / 缺产品名 / 明显字体差异 | **赝品** |
| 指示灯 | 状态不对 | **赝品** |
| 瓶体 | 可见裂纹等损坏 | **不可使用** |
| 状态 | 已空 / 已过期 | 无价值 |

> 社区"免疫宁一直鉴定一直错"的根因就在这 —— 它要**同时**过序列号区间、批次召回表、标签、指示灯四关。

## §7 海明威香烟 Cig（真伪型，无加减算式）

手册：海明威香烟真伪鉴定手册（`ins_cig_*`）。**一项命中即赝品**，无部分正确。

| 检查项 | 判据 |
|--------|------|
| 字母印刷 | 拼写错误、文本错位、印刷不均匀、颜色/字体差异、**缺失字母** |
| 商标 | 形制与正品不符 |
| 颜色 | **须用色卡比对** |
| **防伪标** | **正品绝不会在没有防伪标的情况下出售**；缺失或破损 → 赝品（硬判据） |
| 包装盒 | 盒体本身的差异 |

大小写必须**完全正确**（`ins_general_only_correct_case`）。典型赝品：`HEMINGWAY` → `Heminway`。

## §8 水 Water（靠仪器，非放大镜）

手册：水资源交易手册（`book_water_*`）。**官方区间**如下（与旧 `[二手]` 口径不同，以此为准确）：

| 等级 | 官方纯度区间 | 肉眼可辨 | 安全 |
|------|--------------|----------|------|
| 纯水 | **99.9%+** | 否 | 适宜饮用 |
| 优质水 | **99%–99.9%** | 否 | 适宜饮用 |
| 基础水 | **98%–99%** | 否 | 适宜饮用（短期） |
| 幽灵水 | **96%–98%** | **否**（与优质水肉眼无法区分） | **不安全** |
| 铁锈水 | **90%–96%** | **是** | 警告 |
| 沟渠水 | **90% 以下** | **是** | **剧毒** |

- 仅 **基础水及以上**可售；幽灵水贴基础水标签出售是下层区常见骗局
- 靠**试纸 / 水质检测试剂盒 / 净水器面板**读纯度；肉眼只能分沟渠水与铁锈水
- 净水手段：净水药片（去微生物）/ 滤水器（装水罐内，去杂质·微塑料·有机废物，有耐久）/
  专用净水器+模组（更高纯度）；**不推荐净化沟渠水**（极损滤水器耐久）

## §10 鉴定费与精度反馈

- 鉴定费 = **基础费用 + 按鉴定精度的百分比**：`appraisal_slip_body` = "{0}信用点（{1}%）+ {2}信用点（基础费用）"
- 精度档（`appraisal_quality_*`）：**完美 / 极佳 / 良好 / 一般 / 糟糕** —— 对应 NPC 的接受反馈
- NPC 反应池：`appraisal_accept_*`（正合适 / 稍高 / 稍低 / 太离谱）
- 判定门槛：社区口径 **90% 即通过** `[二手]`（官方文本未给阈值）
- 客户耐心耗尽台词：`appraisal_patience_1/2`（"你显然根本不懂鉴定"）

## §11 已知边界

- §2 机械手的**铝合金 / 镀金 / 装甲 / 刀刃**具体加减值，官方手册只列条目未给数值 —— **不编**。
- §2 套装加成（战术型 / 豪华型）的**加成数值**手册未给。
- §4 化学 7 档与 `val1..val7` 的对齐为**推断**（修正值单调 + 档位单调），未经运行时验证。
- 各品类的**基础价值表**仅覆盖已收录的 4 类（肋明治 150 / 机械手 100 / 燃料匣 100）+ 化学（按档修正）；其余品类基础值待补。
