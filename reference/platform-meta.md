## 6. 显示与操作（官方已确认的便利项）

- 原生 **16:9** 像素画风；21:9 / 32:9 显示器**会窗口化运行**，不铺满 `[官方]`
- 商店页特性包含：Adjustable Text Size、Custom Volume Controls、Playable at your own pace、
  Playable without Timed Input、Stereo Sound `[官方]`
- **"没有时间概念"** —— 玩家实测游戏更接近回合制，暂停对时间无意义；
  但 `Esc` 会先逐层关闭已打开的窗口（参考表、库存等），关闭顺序不直观 `[二手]` 玩家反馈帖

## 8. MOD（非官方，社区高频提问）`[二手]`

作者**重视 mod 生态**，目前社区已有若干内容量不小的 mod。

### 8.1 MOD 前置安装器

| 项 | 说明 |
|----|------|
| 常见方案 | **MelonLoader**（社区也见 `XIAOWOLoader x64` 完全离线版） |
| 安装方式 | 解压压缩包 → 丢进游戏主程序 `.exe` 所在目录 → 启动游戏即可 |
| 优点 | 离线版**内置便携 .NET、Cpp2IL 和 Unity 依赖**，不需要装器、不需要配置代理、不需要输命令 |
| 限制 | **仅支持 Windows 64 位 Unity 游戏**；首次启动 IL2CPP 游戏需生成程序集，等待时间稍长属正常 |
| 建议 | 安装前**备份原有文件** |

### 8.2 内容解锁补丁

社区流传的 `Probably-Stolen-Network-Unlock-Mini-*.zip` 可以解锁王尔德升级项：

- 使用方式：解压到游戏目录 → 运行补丁 → 进游戏开新档（旧档从 beta 迁移可能丢内容）
- **不解锁**的四项：`水培`、`化学制作`、`枪械制作`、`枪械许可` —— 这几项不仅未开放，
  而且**没做完，解锁会出没用的物品和人物**
- 想玩到最多内容：正式版打一次补丁 → 换到 beta 版再打一次 → 进同一个档
