## 1. 总原则

- 利润来自**正确鉴定**：低价买入的前提是你知道它真实值多少。
- **供应商总是夸大价值**，顾客总是得寸进尺 `[官方]`。
- 错判物品**或**错判卖家，损失全部由你承担 `[官方]`。
- 大部分亏损发生在**收购柜台**，不是销售柜台。

## 2. 通用算式：起始值 − 减值 + 加成，且有地板价

每一类可鉴定物品都有一组**起始价值**和**最低价值**，写在游戏内的鉴定手册里。`[二手]`

判定流程（以仿生手为例，**官方手册示例**）`[官方-解包]`：

```
起始价值 100
+50     碳复合材料
-35     磨损
+45     EMG+
────────────
=160 信用点
```

另一个官方示例演示地板价：`100 −85(受损) −60(规格不明接口) = −45 → 但不可低于 50 → 50`。

> 社区旧口径「神经链接控制器 +120 / 装甲 +50」在官方手册中**不存在**（改成 EMG+ +45 / 规格不明 −60），
> 完整判据表见 [appraisal-calc.md §2](./appraisal-calc.md)。

再看是否命中特殊分类加成（仿生手是「战术 / 豪华」两类）。

**两个最容易踩的坑** `[二手]`：

1. **地板价机制** —— 就算物品烂到极致，价格也不会低于一个固定下限。判太低会被判"严重错误"。
2. **"有此标记更值钱，但没有也不扣分"** —— 手册里有些条件只加不减，看到没命中就跳过下一步，
   不要习惯性减分。

## 3. 香烟（以海明威为例）

流程：**放大镜 → 打开鉴别指南 → 逐项比对** `[官方]`

指南里的检查项 `[官方-截图]`：

| 检查项 | 说明 |
|--------|------|
| 字母印刷问题 | 拼写错误、文本错位、印刷不均匀、颜色 / 字体差异、缺失字母 |
| 商标问题 | 商标形制比对 |
| 颜色问题 | **用色卡对比** |
| 防伪标问题 | **正品绝不会在没有防伪标的情况下出售**；防伪标缺失或破损 → 判定为赝品 |
| 包装盒问题 | 包装盒本身的差异 |

典型赝品特征示例：正品 `HEMINGWAY`，赝品拼作 `Heminway`（少一个字母）。`[官方-截图]`

命中赝品后可以**对质**，从而压低收购价。

## 4. 水（另一套完全独立的流程）

水的鉴定不靠放大镜，靠**仪器**。

| 手段 | 能做什么 |
|------|----------|
| 肉眼 | **只能分辨沟渠水与铁锈水** |
| 试纸 / 水质检测器 | 幽灵水往上肉眼无法分辨，必须靠检测 |
| 水质分析仪 | 可分析出微生物、重金属等具体杂质含量 |
| 紫外线灯 | 杀死微生物类杂质 |

品质阶梯（低 → 高）：**沟渠水 < 铁锈水 < 幽灵水 < 基础水 < 优质水 < 纯水** `[官方-解包]`

官方纯度区间：纯水 **99.9%+** / 优质 **99–99.9** / 基础 **98–99** / 幽灵 **96–98** / 铁锈 **90–96** / 沟渠 **<90**
（**修正**：早期"幽灵水≈基础水（同区间 96–99）"的口径已被官方文本推翻 —— 两者区间不同，
但**都肉眼不可辨**、均须检测。完整表见 [appraisal-calc.md §8](./appraisal-calc.md)）

- 只有**基础水及以上**可以出售 `[二手]`
- 幽灵水**有害健康**；基础水能喝；**上层区居民只喝优质水和纯水** `[二手]`
- 常见骗术：拿幽灵水冒充基础水卖给不识货的人 `[二手]`

> 水质检测器约 300 元，收水前越早买越好 `[二手]`

## 6. 复合物品（最难的一类）

### Ribwich 肋明治（官方手册**全文已解包**）`[官方-解包]`

基础 **150** / 地板 **40**。完整判据表 + 算式见 **[appraisal-calc.md §1](./appraisal-calc.md)**，速览：

- 共 **35** 家包装工厂，放大镜读包装上的编号
- 高品质工厂：**01, 02, 05, 08, 21, 34** → **+50**
- 低品质工厂：**07, 15, 18, 26, 31** → **−50**
- 编号**缺失或无效 → 直接判赝品**（旧口径写的"不做加减"有误）
- 第一批次 **425/01–429/12** → +80；首月 01/425 与末月 12/438 → +50
- 豪华版（芝麻面包 **且** 加量酸黄瓜）→ +300；只满足其中一项 → **赝品**
- 双层肉饼 → **+800**
- 达夫雷标志缺失/错误 → **赝品**；第二批次缺 Ribwich 贴纸 → **赝品**（第一批次本就无贴纸）

典型情形：一个"豪华版、加肉、产自优质设施"的三明治本应极贵，
但如果**包装是打开的**，价值立刻掉到 40。漏看这一项就是纯亏。`[二手]`

## 7. 鉴定执业（另一种赚钱方式）

### 7.1 拿到证还不算开张 —— 必须把证挂出来

- 缴纳费用加入鉴定委员会拿到**鉴定许可证**后，**必须把证挂在展示柜/橱窗上**，才会固定概率刷新
  「需要鉴定的客人」`[二手]`（贴吧多帖一致）
- 社区里大量玩家前 40 小时「根本不知道鉴定许可证要挂橱窗」，据此以为鉴定没实装 —— 这是最常见卡点
- 挂证后的吸引权重：鉴定委员会初级证书 → 拾荒客 33% `[官方-截图]`
- 鉴定本身**不花钱**，只要计算和观测

### 7.2 收入量级

| 项 | 值 | 出处 |
|----|----|------|
| 计价方式 | 与**被鉴定物的总价值**挂钩，不看你的等级 | `[二手]` |
| 前期单次 | 约 **100 信用点**（「每次来鉴定顾客基本都能赚 100」） | `[二手]` |
| 稀有品单次 | 双层首批次三明治一次 **154** 鉴定费 | `[二手]` |
| 入门成本 | **85 信用点**换鉴定许可（另一说第一周第 5 天需备 **175** 开鉴定，两数并存待核） | `[二手]` |
| 回本速度 | **1–2 次即可回本**（送的放大镜直接卖了也能回本一半） | `[二手]` |
| 准确率门槛 | 判定「只要 **90%**」即可通过，不是 95%+ → 多报 5% 反而多赚 | `[二手]` |
| 生命周期 | 纯前期生意，**约用十几天**；后面主卖水就不再挂鉴定证 | `[二手]` |

## 8. 赝品判定规则

- 命中「赝品」后，**最终价值一律压到地板 40**，其余条件不再累加 `[二手]`（多帖一致）
- **反例存在**：有玩家把某件货判 40，被 NPC 回「低的离谱」 —— 说明地板价可能受词条修正
  或判定分支影响，**这条不是绝对规则** `[二手]`
- 判错代价自负：**自己没看出赝品、当正品收进来，被 NPC 识破就是里外里亏完** `[二手]`
- **正品当赝品卖**的情形：
  - 你指出这是正品 → **加声望**
  - 对质时选「这是正品」：**错了没惩罚，对了会涨价且加好感**（即使不买下来也加）`[二手]`
- **赝品不等于废品**：只是折价 + 效力略低，药效仍在（哨兵综合征下仍能把计时重置两三天）

## 9. 赝品 / 正品的出货出口

| 出口 | 条件 | 说明 |
|------|------|------|
| 改标签卖上层区 | 有改标能力 | 溢价约 **200%**；但**伪装成上层医院供应商的伪人**带检测器，会拆穿并扣声望 |
| 卖伪人 | **非**医院供应商型 | 吃改标医疗品的 200% 溢价；「假货 + 明确说是假的」不掉声望 |
| 凑单批发 | 真假混批比单买正品划算时 | 赝品食品券唯一的现实用途 |
| 正常挂牌卖 | 不改标签 | 商人照样收，只是利润低 |
| 直接扔 | 无法使用的残品 | 有人凑单买下后扔垃圾桶 |

赝品香烟「可以骗骗上边人」；赝品食品券 / 赝品粮票「只能卖同行」，多数玩家直接跳过不鉴定。

## 11. 高端仿制品的识别要点 `[二手]`

进入中后期会出现**高端仿制品**，特征是**只有一个字母的字体出问题**，或需要**色卡仔细对比**，
或**花纹粗细变化**这类小细节。需要耐心和眼力。

社区归纳的「错误类型」清单（命中任一即为赝品）：

- 编号 / 批次印刷异常：**6 位数**、**召回批次**、**印刷三行变两行**
- **指示灯**状态不对
- **颜色**不对（最罕见的类型，必须色卡；海明威是典型）
- 商标形制：如放大镜里商标十字架的某条臂形状不符
- 字体 / 拼写：缺字母、字体不一致

玩家提示：**不要忘记套装加成**（原帖未展开，按 `[二手]` 线索记录）`[二手]`。
