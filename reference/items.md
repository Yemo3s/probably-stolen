## 1. 水线全套（问得最多的一组）

### 1.1 储水容器（「有哪些桶 / 瓶」问这里）`[官方-解包]`

游戏里**没有**独立的「水桶」道具类，能装水的是这几件：

| 容器 | 官方描述 | 备注 |
|------|----------|------|
| **桶装水** | 解包文本为空 | 容器档位里最大的一档；社区有「6L 大桶」的实测口径 `[二手]` |
| **瓶装水（微型 / 小 / 标准 / 大）** | 四档均为空描述 | 「瓶 + 水」一体成品；**空瓶可单独存在**并参与交易 |
| **水罐** `water_pitcher` | 「可安装滤水器，在倒水时去除部分污染物」 | **唯一能装滤芯的容器**；幽灵水→基础水就走它 |
| **酒瓶** `wine_bottle` | 「用于发酵葡萄酒的精致玻璃瓶。此酒瓶带有内置的气塞。」 | 只用于酿酒 |
| **空啤酒瓶** | 「酿酒厂一般都有针对空瓶的『回购』业务」 | 可回收换钱；凑租金的小额来源 |
| **瓶装泉水** | 「取自一个遥远且未受任何工业活动污染的星球上的天然活泉」 | 稀有成品水，不是容器 |

- 水瓶打印机：官方写「能够制造**小型**水瓶」，社区口径可打 **小瓶 / 普通 / 大瓶** 三档 `[官方-解包]+[二手]`
- 买水**附带空瓶**；一个水卖家约带 3200ml 附瓶，不够用 3D 打印，**一个小水瓶 4 点** `[二手]`

## 3. 模组（机器用什么、怎么配）

| 模组 | 效果 |
|------|------|
| 性能 / 效率 / 质量 / 精炼 / 优化 / 超频 / 环保模组 | 七种基础系统模组；**效率 = 省电、性能 = 产能、质量 = 纯度/品质** |
| **神经核心（受限）** | 「内置安全防护机制，在限制其失控行为的同时，**也限制了它的性能**」 |
| **神经核心（无限制）** | 「性能极高，但不稳定且**属于违禁品**…有失控暴走的倾向」 |
| **节点（小 / 中）** | 「安装在特定机器中时，可提供或**接收相邻模组的加成效果**」 |
| **空白模组** | 可用机器重写成有用模组 |
| **损坏 / 报废 / 故障模组** | 可修（电子元件）或拆解回收 |
| **模组提取器**（基础 / 高级） | 取出卡住的模组。基础版「可使用 {0} 次，可用电子元件翻修」；**高级版无损耗** |
| **模组舱扩建套件** | 扩展模组容量；「与化学或其他特殊机器**不兼容**」 |
| **熔炉模组（高炉）** | 「以 {0} 材料制作 {1} 金属锭（**纯度略低**）。不可叠加」 |
| **熔炉模组（垃圾处理）** | 把垃圾处理成废金属 |
| **金属打印模组** | 让打印机用金属打印 |
| **水培模组 ×7** | 梦帽菇中和 / 梦帽菇梦魇化 / 填料草增产 / 水培芦苇滤芯 / 韧棉自动织造 / 营养果增产 / 水培走私 |
| **蒸发器溶剂回收模组** | 仅回收溶剂 |
