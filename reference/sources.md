## 1. 三级可信度

| 标注 | 含义 | 可用作结论吗 | 典型来源 |
|------|------|--------------|----------|
| `[官方-解包]` | **从游戏本体解出的文本与结构**（最高等级） | 可以，但须区分「可玩范围内」与「解包可见但未开放」 | 本地化表、`dump.cs`、`catalog.json`，见 [datamine.md](./datamine.md) |
| `[官方]` | 开发者 / 发行商直接发布的一手材料 | 可以 | Steam 商店页、Steam 更新日志（UPDATE / Playtest Patch）、官方预告 |
| `[wiki]` | 第三方攻略站整理，标注了自身出处与核对日期 | 可以，但需带核对日期 | probablystolenwiki.com、probablystolen.store、probablystolen.wiki |
| `[二手]` | 玩家个体转述、攻略自媒体、社区帖 | **不可以**，只能作为线索 | Steam 讨论区、NGA、S1、今日头条、18183、下载站攻略页 |
| `[未核实]` | 无任何可追溯来源 | 不可以，必须显式说明 | 模型推测、传闻 |

补充规则：

- `[二手]` 只要被 `[官方]` 或 `[wiki]` 交叉印证过，就升级为 `[wiki]`，并把两处来源都写上。
- 截图读数（从官方截图上直接读出的数值）记为 `[官方-截图]`，因为它是单帧单版本，会随更新漂移。
- `[官方-解包]` 与 `[官方]` 冲突时**以解包为准**（解包是代码实际内容，商店页文案可能滞后）。
- 引用解包数据时，**必须检查该项是否属于 demo 未开放内容**（文本表含正式版全量）。判据见 [datamine.md](./datamine.md) §2。
- **所有数值必须附游戏版本**。没有版本号的数值不允许输出。

## 3. 别名表（触发词）

官方中文名与民间叫法不一致，尤其是「的 / 得」和「当铺 / 当舖」，检索时必须全收。

| 类别 | 写法 |
|------|------|
| Steam 官方简体中文名 | 深空当铺：可能是偷得 |
| 民间常用写法 | 深空当铺、深空当铺：可能是偷的、可能是偷的、可能是偷得 |
| 繁体 / 台湾译名 | 深空當舖、深空當舖：可能是偷的 |
| 英文全名 | Probably Stolen: Cyberpunk Pawnshop Simulator |
| 英文简称 | Probably Stolen、PS（上下文明确时） |
| 开发期旧代号 | Deepspace Emporium、Space Looter（原型） |

**注**：`偷得` / `偷的` 两种写法都真实存在（Steam 官方页用「偷得」，多数媒体报道用「偷的」），
不要纠正玩家，两种都当命中。
