## 1. 品质阶梯（官方分级，带纯度区间）

来源：游戏内 Water Trading Manual — **文本版已解包** `[官方-解包]`（`book_water_s1_*`），
截图版为 official_04.jpg（已移出发布包） `[官方-截图]`，UPDATE 049。**两者冲突以文本为准**。

| 等级 | 官方纯度区间（文本） | 手册说明 |
|------|----------------------|----------|
| 纯水 Pure Water | **99.9%+** | 适宜饮用；上层区待客彰显地位 |
| 优质水 High-Quality | **99%–99.9%** | 适宜饮用；上层区标准用水 |
| 基础水 Basewater | **98%–99%** | 下层区标准用水，长期接触可能致病 |
| 幽灵水 Ghostwater | **96%–98%** | **肉眼无法与优质水区分**，未过滤饮用不安全；常用于农业工业 |
| 铁锈水 Rustwater | **90%–96%** | **可肉眼识别**；不适合灌溉，饮用危险 |
| 沟渠水 Gutterflow | **低于 90%** | **可肉眼识别**；严重污染带剧毒，误饮立即就医 |

> **修正**：旧口径把幽灵水与基础水写成"同区间 96–99"、纯水写"≥99.94" —— 官方文本给出的是上表区间，
> 两者**区间不同**但**都肉眼不可辨**（须试纸/试剂盒）。完整判据见 [appraisal-calc.md §8](./appraisal-calc.md)。

**只有基础水及以上可售** `[二手]`。上层区居民只买优质水和纯水 `[二手]`。

## 2. 杂质模型（这是提纯玩法的根基）

扫描仪一帧实测读数 `[官方-截图]` official_04.jpg：Water 59.6% / Heavy Metals 18.9% / Microbes 11.0% / Chemical Contaminants 9.9% / Physical Contaminants 1.9% / Organic Waste 1.6% / Minerals 4.1%（TESTED 91.96%，RUSTWATER）。

- 微生物可用**紫外线灯**（永久）或**净水药片**（一次性）杀灭 `[二手]`

## 3. 纯水怎么获得（四条路线）

### 路线 A · 机器堆质量（主流，可自动化）

| 装置 | 门槛 | 说明 | 出处 |
|------|------|------|------|
| **水分收集器** 质量 150% | 需堆模组 | 直接**每日产出纯水**，量产首选；顶配加"神经核心模组（受限）+ 涡轮增压器" | `[二手]` 头条全攻略 09-21 |
| **净水器** 质量 100% | 门槛低 | 也能出纯水，但周期长、产量被水分收集器完爆 | `[二手]` 18183 + 头条 |

- 模组分配原则：前期堆性能（产量），后期堆质量；**效率不用考虑** `[二手]`
- **神经核心模组**（稀有受限）：地下交易所 **2 普通模组换 1 个**（约 20 天刷新一次）；或工程箱掉落 `[二手]` 18183
- **涡轮增压器**：每 4 天加速其他机器一次，越多越好 `[二手]` 头条
- 水分收集器基础产出：**一台一次 4 电 / 1000ml**（幽灵水档）`[二手]` 斗鱼叶谳

#### 集水器模组换算表 `[二手]`（2026-09-29 补入）

| 属性 | 换算规则 |
|------|----------|
| **质量 Quality** | **每满 50% 提一档品质**：50% → 优质水；**150% → 纯水** |
| **性能 Performance** | **每 1% = +10ml** 产量 |
| **效率 Efficiency** | **每 25% = −1 电** |
| 基础输出 | 1000ml 幽灵水 / 4 电（未装模组） |

> 与 [furnace.md](./furnace.md) 的熔炉规则对照：熔炉是"质量每 100% 一档"，集水器是"每 50% 一档" ——
> **两台机器的换算步长不同，不要混用。**

> ⚠️ 注：此处"质量 50% → 优质水"与 §3 表格及 §9 冲突表里的"需 150% 才出纯水"并不矛盾，
> 是**同一台机器的两个档位**；但**性能每 1% = 10ml** 这条只在本源（贴吧实测）出现，未见第二源印证。

### 路线 B · 老鼠屎稀释法（机制漏洞，操作繁琐）

原理 `[二手]` S1 与天争锋_L（2026-08-31）：

```
① 把水净化到只剩"过滤不掉的那两种杂质"
② 加入老鼠屎 → 大量新杂质稀释这两种的占比
③ 海德拉净水器按百分比削所有杂质 → 回到基础水档
④ 再过滤掉老鼠屎 → 纯水
```

- 同源印证：游戏新知/雪球报道"往优质水投放老鼠屎，先降纯度再净水，得到更高纯度" `[二手]`
- S1 自己的结论：**一般卖优质就够了，这条路操作太烦、鼠屎日产量有限** `[二手]`
- 给水加老鼠屎会直接变"粪水"改变性质 `[二手]` NGA

**具体配方（2026-09-29 补入，贴吧实测）** `[二手]`：

```
450ml 优质水  +  6 份老鼠屎
      ↓ 海德拉净水器
   98% 基础水
      ↓ 带滤芯的水壶（滤水器容器）
   99.95% 纯水
```

即：**基础水档是最低可售档，只要用带滤芯的容器再过一道就能顶到 99.95%**。

### 路线 C · 单步勾兑速查 `[二手]`（2026-09-29 补入）

| 输入 | 一步操作 | 输出 |
|------|----------|------|
| 幽灵水 | 装进**带滤水器的容器** | 基础水 |
| 基础水 | 过**净水器** | 优质水 |
| 优质水（≥99%） | 直接卖上层区 | +50% 溢价 |

这条链的意义：**幽灵水可以救**，不必须丢；且从幽灵水到优质水只需容器 + 净水器两步。

### 路线 D · 收购 + 勾兑（有交易惩罚时最好用）

头条全攻略的收水判据 `[二手]`：

| 收来水的纯度 | 处理方式 |
|---|---|
| ≥96% | 用装了滤芯的水罐直接净化 |
| ≤95% | 先用海德拉净水器拉到 98%，再净化 |
| 离 99% 不远 | 用其他高纯度水**勾兑** |

目标全部拉到 99% → 优质水 → **+50% 溢价**卖。

## 4. 优质水速成（新手印钞机）

挂水霓虹灯牌收幽灵水/基础水 → 水壶滤嘴或净水药片过一道 → 优质水 `[二手]` NGA。**判据：来源水的有机+重金属 < 1% 就是优质水** `[二手]` 斗鱼。

- 取水器的水过消杀（药片/紫外灯）+ 过滤器，两道工序到优质，日纯利约 400 `[二手]` 斗鱼
- 理解机制后出水稳定在 **99.2%–99.3%**，不需要兑水 `[二手]` 斗鱼
- **不要过滤沟渠水/铁锈水**，极大损耗滤嘴耐久 `[二手]` NGA
- 报废滤嘴别扔：**3 个零耐久滤嘴 → 清道夫服务换 1 个全新** `[二手]` 斗鱼 + 18183
